# MCU Release Log

每个版本使用唯一的 `## vMAJOR.MINOR.PATCH` 章节，在打 tag 前提交。GitHub Release 从该 tag 中提取说明，不读取发布后变化的文档。

## v0.9.1

- tag 自动完成主机测试、ARM 构建、OTA 搬运模型与时钟寄存器检查，通过后创建 GitHub Release，并提供 OTA 应用、调试恢复包、版本记录和 SHA-256 校验文件。
- 发布说明按 tag 从已提交的 Release Log 提取，缺失、重复或未完成的章节会阻止发布；重跑时核对已有发布内容，不覆盖不同的镜像或说明。
- 包含从 v0.9.0 起采用的 tag + 六位 commit hash 版本、GCLK2 看门狗分频修复，以及传感器、显示、RTC、按键、蜂鸣器、PA24 和主控升级的现有实现。
- 当前为开发预览，实机启动、外设时序和真实 OTA/断电恢复仍未完成验收；此前原厂 Boot 保留条件下的应用启动失败，尚无修复候选的实机恢复证据。

## v0.9.0

- 主控版本从 v0.9.0 起按 Git tag 生成，并追加当前 commit 的前六位 hash；UART 查询、构建记录及 Actions 产物名称使用同一版本快照。
- 修复 GCLK2 分频字段溢出造成看门狗周期意外缩短的问题，增加寄存器回读、同步等待及 ARM 时钟模型检查。
- 本 tag 提供 Actions 开发候选；当时尚未接入自动 GitHub Release，实机启动与升级恢复未验收。
