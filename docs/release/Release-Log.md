# MCU Release Log

每个版本使用唯一的 `## vMAJOR.MINOR.PATCH` 章节，在打 tag 前提交。GitHub Release 从该 tag 中提取说明，不读取发布后变化的文档。

## v0.9.4

- 增加完整传感器响应缓存与只读查询接口（0x70 / OP 0x10、schema 1），支持经配套 Wi-Fi 网络桥接分块读取；包含采集代数、帧龄、健康及校验/预热/过滤标记，防止拼接不同采集周期的数据。
- 解码 PM 完整 32 字节帧：CF=1 与大气环境两套 PM1.0/PM2.5/PM10、六档累计颗粒数、版本与错误字节；保留原有 PM2.5 采样、预热、突变过滤和普通上报行为。
- 提供甲醛原始浓度与未知字节、SHT 温湿度原始字及未补偿换算值、状态位和辅助响应；未知字段保留原始数据，不解释为新增环境测量。
- 增加 tools/m1_sensors.py，通过网络核对设备身份并读取 JSON，也支持完整帧离线解码。新增数据目前由工具按需查询，配套 Wi-Fi 的自动采集、网页展示与额外 MQTT 上报尚未加入。
- 已在一台 M1 完成开发候选网络 OTA 和连续读取，所有已捕获测量及状态/辅助响应校验通过，PM1.0/PM2.5/PM10 读到非零值 13/19/19 μg/m³，颗粒计数也有非零数据；升级后网络、传感器健康正常，音乐及原有配置保留。两种探测应答本次未捕获。
- 增加完整帧、坏帧保留、代数一致性、参数边界及工具回归测试；主机测试、ASan/UBSan、OTA 安装模型与 ARM 时钟模型通过。PM 额外字段按兼容协议解码，模块型号与计量精度仍需独立验证；本版仍为开发预览，发布镜像与开发候选的硬件证据分别记录，未完成真实断电、故障注入或长期稳定性验收。

## v0.9.3

- 增加四种单次 PWM 提示音及扩展能力位；主控负责到期停止，保留普通蜂鸣器策略和 OTA 互斥。
- 增加 RTTTL 单音音乐解析、非阻塞播放及一首曲目的双槽持久化；上传校验、顺序/重传检查、元数据最后提交，数据区与应用、OTA 暂存和 Boot 分离。
- 配套联网固件 v0.9.27 / WebUI 可写入、读取、播放、停止音乐，并作为闹钟曲目；按主控版本及真实能力启用。
- 时间冒号亮/灭各 500 ms，不加速正常 3 秒数值快照。原始段调试及全段测试保持字节原义；尚未确认原厂备份中的每秒闪烁代码路径。
- 修复网络升级工具在重刷同版本时提前接受旧版本缓存的问题；须等待升级状态结束及新的主控版本回报。
- 已在一台 M1 完成候选网络 OTA、真实 WebUI 曲目写入/逐字读回、播放/停止、闹钟到期停止及再次 OTA 后曲目保留测试，用户确认蜂鸣器发声。冒号相位已由显示缓存回读验证；未做示波器、声压、真实掉电中断或全部硬件修订验收。
- 音乐在部分音区声音偏小，提高八度未明显改善；本版没有音量放大功能。主机故障注入及 ARM 模型结果与实机结果分别记录。

## v0.9.2

- 按原厂采样与屏幕节奏更新读数，补齐 PM2.5 两种串口格式、预热及突变处理，保留 PA24 复位时序与温湿度恢复流程。
- 通过原厂 0x05/0x06 设置甲醛、PM2.5 两档阈值，同步控制绿/黄/红灯色及红档蜂鸣器告警；提供阈值核对与主机回归测试。
- 增加 0x70 扩展协议：主控能力查询、CO₂ 数据、屏幕位置替换或按秒交替、阈值配置及调试。显示 CO₂ 时隐藏原甲醛/PM 标识和单位，数据超时恢复原读数。
- 提供经配套 Wi-Fi 固件转发的网络升级工具，校验设备身份、目标镜像、分块应答及升级后版本；升级应用不覆盖原厂 Bootloader。
- 本版本仍为开发预览；真实断电恢复、全部外设电气波形和所有原厂硬件修订尚未完成验收。CI 的 Flash/时钟模型结果与设备运行记录分别保存，不能互相替代。

## v0.9.1

- tag 自动完成主机测试、ARM 构建、OTA 搬运模型与时钟寄存器检查，通过后创建 GitHub Release，并提供 OTA 应用、调试恢复包、版本记录和 SHA-256 校验文件。
- 发布说明按 tag 从已提交的 Release Log 提取，缺失、重复或未完成的章节会阻止发布；重跑时核对已有发布内容，不覆盖不同的镜像或说明。
- 包含从 v0.9.0 起采用的 tag + 六位 commit hash 版本、GCLK2 看门狗分频修复，以及传感器、显示、RTC、按键、蜂鸣器、PA24 和主控升级的现有实现。
- 当前为开发预览，实机启动、外设时序和真实 OTA/断电恢复仍未完成验收；此前原厂 Boot 保留条件下的应用启动失败，尚无修复候选的实机恢复证据。

## v0.9.0

- 主控版本从 v0.9.0 起按 Git tag 生成，并追加当前 commit 的前六位 hash；UART 查询、构建记录及 Actions 产物名称使用同一版本快照。
- 修复 GCLK2 分频字段溢出造成看门狗周期意外缩短的问题，增加寄存器回读、同步等待及 ARM 时钟模型检查。
- 本 tag 提供 Actions 开发候选；当时尚未接入自动 GitHub Release，实机启动与升级恢复未验收。
